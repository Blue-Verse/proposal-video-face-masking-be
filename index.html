핵심 요구사항 분석

  • 영상 얼굴 마스킹 및 분리 저장 — 업로드 영상의 얼굴 자동 검출 후 마스킹(블러/모자이크) 처리, 원본과 가공본을 분리하여 저장
  • 유료 권한 기반 영상 제공 — 마스킹 해제(유료) 요청 시 보관 중인 원본 영상을 권한 확인 후 제공
  • S3/CloudFront → Cloudflare R2 마이그레이션 — 기존 AWS 스토리지 환경에서 Cloudflare R2로 이전하고 스트리밍 환경 재구성
  • 일회성 보안 URL 발급 — 기업 고객/관리자가 원본 영상 조회 시 약 5분 만료 보안 URL 발급
  • 워터마크 삽입 — 영상 유출 시 어느 기업/사용자인지 식별 가능한 워터마크 삽입 처리
  • API 명세서 산출 — 백엔드/스토리지/보안 URL 전반에 대한 OpenAPI 기준 명세서 제공

제안 포인트

1. 두 단계 영상 처리 파이프라인

업로드된 영상을 비동기 큐(Celery/RQ)에 적재한 뒤, ① 얼굴 검출(MediaPipe Face Detection 또는 RetinaFace) → ② FFmpeg 기반 블러/모자이크 합성 → ③ 워터마크 오버레이 → ④ R2 업로드의 4단계 파이프라인으로 처리합니다. 원본은 별도 "private/원본" 버킷 경로에, 가공본은 "public/마스킹" 경로에 분리 저장하여 권한 분리를 명확히 합니다.

2. 스토리지 마이그레이션 단일 진입점 설계

S3·CloudFront 환경과 Cloudflare R2를 추상화한 스토리지 어댑터 레이어를 두어, 마이그레이션 기간 동안 양쪽 모두에 쓰기/읽기가 가능한 듀얼 라이트 구조를 적용합니다. 마이그레이션 완료 후 트래픽 컷오버 시 환경변수 한 줄로 R2 단독 모드로 전환되어 다운타임을 최소화합니다.

3. 5분 만료 일회성 보안 URL

Cloudflare R2의 S3 호환 Presigned URL과 자체 JWT 토큰을 결합하여, ① 5분 만료 ② 1회 사용(서버 사이드 토큰 무효화) ③ 요청자 IP/User-Agent 바인딩이 가능한 일회성 URL을 발급합니다. 영상 유출 시 발급 로그로 출처를 역추적할 수 있도록 발급 이력을 DB에 기록합니다.

4. 두 종류 워터마크 동시 삽입

① 시각적 워터마크(반투명 텍스트/로고 오버레이 — FFmpeg drawtext/overlay 필터) ② 비가시 워터마크(LSB 또는 DCT 기반 스테가노그래피)를 동시에 삽입합니다. 화면 캡처 유출 시에는 시각적 워터마크로, 영상 파일 자체 유출 시에는 비가시 워터마크로 추적이 가능합니다.

5. 명확한 API 명세와 인계

FastAPI의 자동 OpenAPI 스펙 생성 기능을 활용하여 Swagger UI/Redoc 형태로 산출물을 제공하며, 추가로 마이그레이션 가이드·운영 매뉴얼·환경변수 명세를 README로 정리하여 운영 인계까지 책임집니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

영상 업로드 기반 콘텐츠 플랫폼에서 사용자의 개인정보(얼굴)를 보호하기 위해, 업로드된 원본 영상을 자동으로 마스킹 처리하고 원본과 가공본을 분리 저장합니다. 유료 구독자는 마스킹이 해제된 원본을 시청할 수 있어야 하며, 제휴 기업·관리자가 원본을 확인할 때는 5분 만료 일회성 보안 URL을 통해서만 접근이 가능해야 합니다.

또한 모든 가공본 및 일회성 URL로 제공되는 영상에는 워터마크가 삽입되어, 유출 발생 시 어느 기업 또는 사용자로부터 발생했는지 역추적이 가능해야 합니다. 이와 함께 기존 AWS S3/CloudFront 스토리지를 Cloudflare R2로 마이그레이션하여 트래픽 비용 구조를 개선합니다.

본 PRD에서 다루는 범위는 백엔드 영상 처리 파이프라인, 스토리지 마이그레이션, 보안 URL 및 워터마크 모듈, 권한 기반 영상 제공 API에 한정합니다. 사용자 인증·결제 처리·프론트엔드 UI는 본 범위 외이며, 기존 시스템과의 인터페이스(권한 정보, 사용자 ID 등)는 클라이언트 측 시스템에서 제공한다는 가정 아래 설계합니다.

3. 기능 요구사항

3.1 영상 업로드 및 마스킹 파이프라인

  • [필수] 멀티파트 업로드 API — 대용량 영상 업로드 (chunk 분할 지원)
  • [필수] 업로드 즉시 비동기 큐(Celery)에 작업 등록, 작업 상태 조회 API
  • [필수] 프레임 단위 얼굴 검출 (MediaPipe Face Detection 또는 RetinaFace, 정확도 기준 선정)
  • [필수] FFmpeg 기반 얼굴 영역 블러 또는 모자이크 합성, H.264 재인코딩
  • [필수] 원본은 private 경로, 가공본은 public 경로에 분리 저장
  • [선택] 마스킹 강도 설정 (블러 반경/모자이크 픽셀 크기 커스터마이즈)

3.2 권한 기반 영상 제공

  • [필수] 사용자 권한(무료/유료) 확인 후 가공본 또는 원본 URL 반환
  • [필수] 원본 영상은 항상 Presigned URL 또는 일회성 보안 URL로 전달 (직접 노출 금지)
  • [필수] 권한 변경 시 기존 발급 URL 무효화 옵션 제공

3.3 일회성 보안 URL

  • [필수] 만료 시간 5분 (설정 가능)
  • [필수] 1회 사용 제한 (서버에서 토큰 사용 여부 추적)
  • [필수] 발급/사용/만료 이벤트 감사 로그 (DB 기록)
  • [선택] 발급 시점의 요청자 IP/User-Agent 바인딩

3.4 워터마크 삽입

  • [필수] 시각적 워터마크 — 기업명/사용자 ID/타임스탬프 텍스트 오버레이
  • [필수] 비가시 워터마크 — LSB/DCT 기반 추적용 워터마크 (추출 도구 함께 제공)
  • [필수] 워터마크 데이터(기업 ID, 사용자 ID, 발급 시각)와 발급 URL 매핑 저장
  • [선택] 동적 위치 변경 (좌상/우상/좌하/우하 랜덤 또는 회전)

3.5 스토리지 마이그레이션

  • [필수] S3/CloudFront ↔ Cloudflare R2 추상화 어댑터 계층
  • [필수] 기존 데이터 일괄 마이그레이션 스크립트 (체크섬 검증)
  • [필수] 마이그레이션 기간 듀얼 라이트 모드 (S3 + R2 동시 기록)
  • [필수] 환경변수 기반 트래픽 컷오버 (다운타임 최소화)
  • [필수] R2 기반 스트리밍 환경 구성 (HLS 또는 직접 스트림)
